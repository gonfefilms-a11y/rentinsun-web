Publicar Rent In Sun

Guía paso a paso para poner la web en rentinsun.com con base de datos real. Tiempo estimado: 30–45 minutos. Coste: 0 € con los planes gratuitos.

QUÉ HAY EN ESTA CARPETA

index.htmlLa web completa (4 idiomas + CRM)
config.jsEl único archivo que tienes que editar: datos de conexión
supabase-setup.sqlCrea la base de datos y las reglas de seguridad
seed.jsLas 32 propiedades actuales, con traducciones (se cargan una vez desde el CRM)
supabase.jsLibrería de conexión (no tocar)
404.html, .htaccess, _headers, robots.txtRedirigen las URL antiguas (rentinsun.com/propiedad/8…) y configuran el servidor

PASO 1 Crear la base de datos

  1. Entra en supabase.com → Start your project y crea una cuenta.
  2. New project: nombre rentinsun, una contraseña de base de datos (guárdala) y región West EU (Paris) o Central EU (Frankfurt).
  3. Cuando termine de crearse, ve a SQL Editor → New query, pega todo el contenido de supabase-setup.sql y pulsa Run. Debe decir Success.

PASO 2 Crear tu usuario de administrador

  1. Ve a Authentication → Users → Add user → Create new user. Pon tu email y una contraseña segura, y marca Auto Confirm User.
  2. Vuelve a SQL Editor y ejecuta esta línea cambiando el email por el tuyo: 
    insert into public.admins (user_id) select id from auth.users where email = 'TU-EMAIL@ejemplo.com' on conflict do nothing;
  3. Por seguridad, desactiva los registros públicos: Authentication → Sign In / Providers → desactiva Allow new users to sign up.
Aunque alguien consiguiera crear una cuenta, la base de datos solo deja editar a los usuarios de la tabla de administradores.

PASO 3 Conectar la web

  1. En Supabase pulsa Connect (arriba) o ve a Project Settings → API Keys. Copia la Project URL y la clave publishable (o anon public).
  2. Abre config.js con cualquier editor de texto y pégalas: 
    window.RIS_CONFIG = {
  supabaseUrl: "https://abcdefghijkl.supabase.co",
  supabaseAnonKey: "sb_publishable_…",
  notifyEmail: "info@rentinsun.com"
};
Esa clave está pensada para ir en la web: es pública y solo permite lo que dejan las reglas de seguridad. Nunca pegues la clave secret ni la service_role.
notifyEmail (opcional): recibirás un email con cada solicitud nueva. La primera vez que alguien envíe un formulario llegará un correo de FormSubmit pidiéndote que confirmes ese email; confírmalo una vez y a partir de ahí los avisos llegan solos. Las solicitudes se guardan siempre en el CRM, con o sin este aviso.

PASO 4 Publicar la web

  1. Entra en app.netlify.com/drop (crea una cuenta gratuita si te lo pide).
  2. Arrastra la carpeta completa a la página. En unos segundos tendrás la web en una dirección tipo nombre.netlify.app.
  3. En Site configuration → Change site name puedes ponerle rentinsun.
Para actualizar la web en el futuro (cambios de diseño), entra en el sitio → Deploys y vuelve a arrastrar la carpeta. Las propiedades no necesitan esto: se gestionan desde el CRM.

PASO 5 Cargar el catálogo y copiar las fotos

  1. Abre https://TU-SITIO.netlify.app/#/admin e inicia sesión con el usuario del paso 2.
  2. Pulsa Cargar catálogo actual: se crean las 32 propiedades con sus traducciones.
  3. Ve a Ajustes → Copiar fotos a mi servidor y espera a que llegue al final (unas 900 fotos, varios minutos). No cierres la pestaña. Si alguna falla, vuelve a pulsar el botón: solo reintenta las que faltan.
  4. Revisa en Ajustes los datos de contacto y cambia lo que quieras.
Importante: haz este paso antes de dar de baja la web actual de Hostinger. Hoy las fotos están en los servidores de Hostinger; tras copiarlas quedan en tu Supabase y ya no dependes de ellos.

PASO 6 Conectar el dominio rentinsun.com

  1. En Netlify: Domain management → Add a domain → escribe rentinsun.com y confirma.
  2. En el panel donde está registrado el dominio (probablemente Hostinger → Dominios → DNS / Nameservers), cambia o crea estos registros y borra los A/CNAME antiguos de @ y www:
    TipoNombreValor
    A@75.2.60.5
    CNAMEwwwTU-SITIO.netlify.app
  3. Espera a que se propague (de minutos a 24–48 h). Netlify activa el certificado HTTPS automáticamente.
  4. En Supabase → Authentication → URL Configuration, pon https://rentinsun.com como Site URL.
No toques los registros MX si tienes el correo @rentinsun.com en Hostinger: el email seguirá funcionando igual.

PASO 7 Comprobación final

  • ✓ La web carga en rentinsun.com con candado HTTPS.
  • ✓ Cambias un precio en el CRM y aparece al recargar desde el móvil.
  • ✓ Envías el formulario de contacto y aparece en CRM → Solicitudes.
  • ✓ rentinsun.com/propiedad/8 lleva a la ficha correcta.
  • ✓ El selector de idioma cambia toda la web.

BUENO SABER

  • Planes gratuitos: Supabase Free incluye 500 MB de base de datos y 1 GB de fotos, de sobra para este catálogo. Pausa los proyectos que pasan una semana sin actividad; con visitas diarias no ocurre, y si se pausara se reactiva desde el panel con un clic. El plan Pro (25 $/mes) elimina esa pausa y añade copias de seguridad diarias.
  • Copias de seguridad: en el CRM → Ajustes → Exportar datos. Hazlo de vez en cuando.
  • Contraseña: se cambia en CRM → Ajustes → Acceso. Si la olvidas: Supabase → Authentication → Users → tu usuario → Send password recovery.
  • Modo demostración: si config.js está vacío, la web funciona igualmente, pero los cambios del CRM solo se guardan en ese navegador (usuario admin, contraseña RentInSun2026).
